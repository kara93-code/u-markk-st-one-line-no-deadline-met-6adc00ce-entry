One single-line joke giving an excuse for a missed deadline, written by a small Node program with no dependencies.

> I missed the deadline because my calendar filed a restraining order after I rescheduled it nine times, and now I'm legally barred from coming within 500 feet of Tuesday.

## Run it

```sh
node main.ts
```

It writes the single-line entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates it is 1–200 characters and a single line, and reads it back to confirm what was written.
